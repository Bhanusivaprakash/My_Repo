# My_Repo

This repository contains my work in **RTL design, FPGA-based digital systems, computational hardware, DSP, and hardware acceleration**.

It includes hands-on implementations of **digital datapaths, memory systems, DMA, arithmetic hardware, FPGA interfaces, DSP blocks, and compute-oriented designs**, along with supporting embedded and electronic hardware projects.

The focus is on understanding computation at the hardware level — from **algorithm and architecture to RTL, verification, synthesis, FPGA implementation, and hardware validation**.
